# A.K.T.A. – 5. akta (grooming) – Robotzsaru Adattár

Oktatási szimuláció a BRFK bűnmegelőzési programjához. Minden szereplő, név, fiók és adat kitalált.

## Feltöltés GitHub Pages-re
1. Töltsd fel az `index.html`, `style.css`, `app.js` fájlokat egy repó gyökerébe (vagy egy almappába).
2. Settings → Pages → Branch: `main`, mappa: `/ (root)`.
3. A kapott linkből készül a nyomtatott jegyzőkönyv QR-kódja.

**A `MEGOLDOKULCS.md` fájlt NE töltsd fel a repóba** (nyilvános lenne).

## Csoportváltás
A haladás a böngészőben tárolódik. Két csoport között a főoldal alján a
„RENDSZER LEZÁRÁSA” gomb mindent visszaállít.

## Helyőrzők, amelyeket később képre lehet cserélni
- Sértett fotója: szándékosan „KITAKARVA” (kiskorú) – maradhat így.
- Nyilvántartási fotók: monogramos szürke kártyák (`.mug`), az elkövetőnél „FOTÓ”.
- Avatarok: kódból rajzolt blokkos figurák (SVG) – nem kell hozzájuk kép.
- Dani képernyőképe a #képek csatornában: HTML-ből rajzolt, a fülek szövege a nyom.
